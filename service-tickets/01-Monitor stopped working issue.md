# INC161250 – External Monitors Not Working After Laptop Docking

**Category:** Hardware / Display  
**Priority:** Medium  
**Status:** Resolved  
**Reported by:** Jessica Tran  
**Department:** Engineering  
**Location:** Floor 1

### 1. Issue Description

The user reported that both external monitors stopped displaying after docking their laptop. Previously, both monitors worked normally when connected to the laptop. However, after docking the laptop, both external displays remained black while the laptop's built-in screen continued to function.

The user was unsure which cables were being used and could not identify the potential cause of the issue.

**Business Impact:**
The user was limited to working on a single laptop screen, making it difficult to work efficiently, particularly when handling spreadsheets and multitasking.

### 2. Troubleshooting & Investigation

I communicated with the user through the company chat to gather additional information and identify the possible cause.

The following steps were taken:

1. **Checked cable connections:** Asked the user whether they had attempted to unplug and reconnect the cables to ensure the connections were secure.
2. **Identified the cable type:** Asked the user to provide a picture of the cable being used to identify the correct replacement. Based on the image provided, I identified it as an HDMI cable.
3. **Confirmed replacement requirement:** Determined that an HDMI cable replacement was needed to restore the external monitor connections.
4. **Collected shipping information:** Requested the user's shipping address to arrange delivery of the replacement cable.

### 3. Resolution

Since the issue required replacement hardware, I used the **Ship Manager** tool to arrange delivery.

Actions performed:

1. Opened the Ship Manager system.
2. Selected HDMI Cable as the equipment to be shipped.
3. Entered the user's shipping address.
4. Selected Rush Priority (Instant) shipping.
5. Included a return shipping label.
6. Submitted the shipment request.

### 4. Outcome

The user received the replacement HDMI cable and connected it to their setup. The user confirmed through company chat that the external monitors were working properly again.

**Final Status:** Resolved – Replacement HDMI cable successfully delivered and external monitors restored to working condition.
