# INC268751 – Customer Support Desktop Power Failure (Computer Completely Unresponsive)

**Category:** Hardware / Desktop Support  
**Priority:** Critical  
**Status:** Resolved  
**Reported by:** David Lee  
**Department:** Support  
**Location:** Floor 1

### 1. Issue Description

The user reported that their desktop computer at the Customer Support department on Floor 1 was completely unresponsive and could not be powered on.

When pressing the power button, the computer showed no signs of activity. There were no indicator lights, fan activity, or beep sounds.

The user had already attempted several basic troubleshooting steps but was still unable to get the computer running.

**User's Report:**

"My desktop on the Customer Support floor won't turn on at all this morning. No lights, no fan, nothing when I press power. I have a full queue and I can't do anything until I have a working machine."

**Business Impact:** The user was unable to access their workstation and perform daily customer support operations, including handling incoming calls and responding to customer enquiries. This caused an immediate disruption to the department's operations, particularly as the user had an active customer support queue to manage.

### 2. Troubleshooting & Investigation

Before escalating the issue to IT support, the user had already performed several basic troubleshooting steps to identify the possible cause.

The following checks were performed by the user:

1. **Attempted to power on the desktop:** Pressed the power button several times, but the computer remained unresponsive.
2. **Checked the power outlet:** Tested the wall outlet using another electrical device to confirm whether it was supplying power. The other device worked successfully.
3. **Observed the computer's response:** Confirmed that the desktop showed no signs of power, including indicator lights, fan activity, or beep sounds.

Based on the initial investigation, the wall outlet was functioning properly, while the desktop remained completely unresponsive.

### 3. Resolution

Since the desktop showed no signs of power despite confirming that the electrical outlet was working, I decided to deploy a replacement desktop for the user instead of continuing with basic troubleshooting.

The following actions were taken:

1. **Accessed the computer deployment section:** Opened the computer deployment module to initiate the deployment process for a replacement desktop.
2. **Selected server imaging:** Chose the server imaging option to begin deploying the new desktop.
3. **Followed the deployment SOP:** Carefully followed the internal Standard Operating Procedure (SOP) to complete the desktop deployment.
4. **Completed desktop deployment:** Finished the deployment process and prepared the replacement computer for the user.
5. **Obtained the user's shipping address:** Contacted the user to request their delivery address for the replacement desktop.
6. **Arranged desktop shipment:** Shipped the newly deployed desktop to the user's provided address.
7. **Confirmed delivery:** Followed up with the user to verify that the replacement desktop had been received safely.

### 4. Outcome

The replacement desktop was successfully deployed following the internal server imaging procedure and shipped to the user's provided address.

I followed up with David Lee to confirm receipt of the replacement computer. The user confirmed that the desktop had been received safely.

The replacement desktop provided the user with a working machine to resume customer support operations.

**Final Status:** Resolved – Replacement desktop successfully deployed using server imaging, shipped to the user's address, and delivery confirmed by the user.
