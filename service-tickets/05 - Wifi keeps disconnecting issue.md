# 1. Issue Description – Wi-Fi Connection Keeps Disconnecting Every Few Seconds

**NET17948777007261 – High**

**Reported by:** Nicole Davis  
**Department:** Sales

**User's Reported Issue:**

"My Wi-Fi keeps disconnecting every few seconds."

**Business Impact:**

Video calls were disconnected three times due to an unstable Wi-Fi connection, preventing the user from maintaining a stable connection for work.

# 2. Resolution Description

**Troubleshooting Steps:**

1. Accessed the Server Room.
2. Navigated to the **Devices** section.
3. Located **Metro ISP (External)** to check the Internet Service Provider (ISP) status.
4. Checked the ISP status and monitored the connection.
5. The connection was restored shortly afterwards.

**User Confirmation:**

Nicole Davis contacted me to confirm that her connection had been restored and was stable again.

User's feedback:

"Hey! My connection just came back – looks like it was just a brief outage that passed. It's stable now, thanks!"

**Resolution Status:** Resolved

**Resolution Summary:** The issue was caused by a temporary ISP outage. The connection was restored after monitoring the Metro ISP (External) status in the Server Room. The user confirmed that the Wi-Fi connection was stable again.
